Packmule · Support

Packmule is a free file mule for iPhone: SMB shares, FTP and SFTP servers and Jellyfin, at home or over a VPN, plus a built in FTP server so your computer can reach the phone.

What can Packmule connect to?

Windows shares, NAS boxes and Samba servers over SMB, any FTP server, Linux machines and anything else running SSH over SFTP, and Jellyfin media servers. Tap Add server and pick the kind. Pasting a Windows path such as \\192.168.1.20\media into Host fills in the share for you.

It says the server refused the sign in

Check the user name spelling first. A Samba server quietly treats an unknown user as a guest, and a share that doesn't allow guests then refuses. The password is the one set on the server with smbpasswd, which isn't always your login password. If your computer opens the share, it is usually signed in with a saved user name you can copy.

Can I reach my home server when I'm away?

Yes, over a VPN. Turn on WireGuard or Tailscale in their own apps, then use the tunnel address in Packmule. If the packets get there, the mule can too.

Where do downloads go?

Into the Packmule folder in the Files app: On My iPhone, then Packmule, then Downloads. Settings in Packmule has a shortcut that opens it.

Why do transfers stop when I lock my phone?

iOS pauses apps shortly after they leave the screen. Packmule picks up where it stopped when you come back, and keeps your queue across a relaunch. Turn on Keep the screen awake while hauling in Settings to keep a long transfer moving.

A file with the same name is already on the server

Packmule asks once for the whole batch: Keep both gives the new copy a number, Replace overwrites the copy on the server, and Skip leaves those files out. It never overwrites without asking.

It says my SFTP server has a new identity

Packmule remembers each SSH server's host key the first time it connects. If the key changes, it stops before sending your password. That's expected after reinstalling or rebuilding the server. If you didn't, choose Stay away: something may be pretending to be your server.

How do I copy files from my iPhone to my computer?

Open Host this iPhone and tap Start serving. Packmule shows an address such as ftp://192.168.1.23:2121. Type it into the Windows Explorer address bar, Finder's Connect to Server, or any FTP app on the same WiFi or VPN. Add a user and password to keep others out, and keep Packmule open while hosting.

Is it really free?

Yes. Every feature is free with no limits: no subscription, no unlock, no ads.

Does Packmule collect any data?

No. There are no accounts, ads or analytics, and files only move between your iPhone and the servers you add. Read the privacy policy.
