# redfernsoutpost.github.io

Public web pages for Redfern's Outpost apps, served by GitHub Pages.

- `Recetario-de-la-abuela/`: home, privacy policy and support pages for Recetario de la Abuela.
  App Store Connect links to these exact paths, so keep the folder and file names as they are.

The root page sends visitors on to redfernsoutpost.com.
